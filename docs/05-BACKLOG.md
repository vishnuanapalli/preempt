# Backlog

Every story, prioritized. `04-PLAN.md` says which sprint each one lands in; this file
says what "done" means for it.

## Priority

- **MUST** — the project does not ship without it.
- **SHOULD** — real value, but the project stands up without it.
- **COULD** — worth doing if time allows.
- **WON'T** — decided against for now. Kept visible, with the reason, so it does not
  quietly return as scope creep.

## Story format

Acceptance criteria are checkable by a test or by direct inspection. "Works correctly"
is not an acceptance criterion; "returns 422 with an `invalid_field` error code when
`region` is not in the supported list" is.
