# Decision log

Append-only. Every consequential choice gets an entry, numbered in the order it was made.

**The rule: never edit a past entry.** If a decision turns out wrong, add a new entry that
supersedes it and mark the old one `Superseded by D-0NN`. The log is a record of what was
believed at the time, not a description of the current system — that is what `01-DESIGN.md`
is for. Rewriting history here destroys the only evidence of how the thinking evolved.

Add an entry when: the choice is expensive to reverse, it constrains later work, a
reasonable engineer would have chosen differently, or it will be asked about in an
interview. Do not log which variable name you picked.
